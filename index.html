Drone Fundamentals

What is a Drone?

An unmanned aerial vehicle (UAV) is an aircraft without a pilot on board, controlled remotely or autonomously. Drones are used in multiple domains: surveillance, inspection, delivery, agriculture, research, and entertainment.

Main Components

Flight Control

Microcontroller, IMU, barometer, compass for attitude and position control.

Motors & Propellers

Electric brushless motors (BLDC) with ESC for speed control.

Power

LiPo batteries for energy, power distribution boards.

Navigation

GPS/GNSS, IMU, altimeter for autonomous flight.

Communication

Radio receiver, telemetry link, MAVLink protocol.

Payload

Cameras, sensors, lidar for perception and data collection.

Drone Swarms

A drone swarm is a coordinated group of autonomous drones working together to achieve a common goal. Swarms enable:

  • Wider coverage: Multiple drones survey larger areas in parallel
  • Redundancy: System resilience if one drone fails
  • Complex missions: Tasks that a single drone cannot accomplish
  • Distributed intelligence: Each drone makes local decisions contributing to the global objective

Key Technologies

  • Decentralized coordination and consensus algorithms
  • Collision avoidance and path planning
  • Communication networks and MAVLink protocol
  • ROS 2 / micro-ROS for distributed robotics
  • Multi-agent reinforcement learning (MARL)
  • Real-time telemetry and state synchronization

Flight Control Systems

PX4 Autopilot

Open-source autopilot stack for drones, multirotors, fixed-wing aircraft, and VTOL systems. PX4 provides:

  • Flight control algorithms
  • Autonomous navigation
  • Sensor fusion and state estimation
  • Mission planning
  • Safety features (RTL, geofencing)

📚 Resources: PX4 Documentation | GitHub Repository

ArduPilot

Alternative open-source autopilot supporting copters, planes, rovers, and submarines.

Regulation & Safety

⚠️ Important: All drone operations must comply with local and national regulations. In Europe, the EASA (European Union Aviation Safety Agency) sets the standards.

EASA Drone Regulation

The EASA defines three categories of drone operations:

1. Open Category

Low-risk operations, simple procedures, for:

  • Recreational use
  • Light inspection
  • Professional use under simple conditions

2. Specific Category

Operations requiring risk assessment and authorization:

  • Complex missions
  • Operations over populated areas
  • Operations near sensitive zones

3. Certified Category

High-risk operations requiring system certification and operator qualification.

Key Considerations for Drone Projects

  • Drone weight and classification
  • Intended use (hobby, professional, research)
  • Flight zone (urban, rural, near people, restricted airspace)
  • Operator qualifications and certifications
  • Emergency procedures and failsafe modes
  • Insurance and documentation requirements
